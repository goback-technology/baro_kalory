## Structure decisions

- **이름은 `baro_kalory` 로 확정.** 형제 저장소 `baro_calrory` 와의 `c`/`k` 차이는 오타가
  아니라 **의도된 말장난**이다(2026-08-04 확인) — **백엔드는 `c`alrory, 프런트는
  `k`alory**. 즉 철자 한 글자가 저장소 구분자다. 다만 `grep` 이 한쪽만 잡는다는 함정이
  있으니, 두 저장소를 함께 훑을 때는 패턴을 `[ck]al` 로 쓴다.
- **광학 모델을 이 저장소에 두지 않는다.** 화각·투영·조준은 백엔드가 계산해 값으로 내려준다.
  두 벌로 갈라지면 조용히 틀린 화면을 그린다.
- ~~무번들 바닐라를 유지한다~~ → **뒤집힘(2026-08-22, 이교수님): React + Vite.**
  원 결정은 앱이 작을 때의 것이고, 「기능 산더미 + 코드 건강 악화」가 전제를 바꿨다.
  2026-08-25 전 화면 전환이 끝났고, Vite 가 자작 도구(`server.mjs`·`pack.mjs`)를 흡수해
  배포는 오히려 단순해졌다(dist 는 문서 하나 + 리다이렉트 셸들).
- **라우팅은 해시다.** 정적 호스트에 깊은 경로용 rewrite 가 없고, 해시는 그 문제를 통째로
  없앤다 — 문서 URL 이 언제나 `index.html` 하나라 상대 참조·버전 파일 경로가 깊이에 따라
  어긋나지 않는다(`v—` 배지 부류의 소멸).
- **폴더는 「같이 고치는 것끼리」로 가른다**(2026-08-25). 종류별이 아니다. `src` 최상위에
  파일을 두지 않는다 — 낱개로 놓이면 「누가 쓰나」를 위치가 말해 주지 못한다.
  구조는 `inventory.md` 가 갖는다.
- **백엔드 주소를 저장소에 박지 않는다.** 사용자가 런타임에 지정한다(`memo.md` 「API 주소
  주입」). 개발 서버의 값도 gitignore 된 `.env` 가 유일한 출처다.
- **백엔드 주소의 기본값을 만들지 않는다(2026-08-04).** 분리 배포에서 "같은 곳에 있겠거니"는
  **틀린 쪽이 정상**이라, 추측하는 대신 미설정 상태를 그대로 드러낸다 — 배너로 알리고 설정·
  대문을 뺀 바로가기를 잠근다. 설정 화면에는 주소를 넣고 바로 확인할 연결 테스트를 둔다.
- **리버스 프록시를 전제하지 않는다(2026-08-04 확정, 이교수님).** 서비스는 각자 자기 포트로
  서고, `barocalory`·`kalory` 는 **프로젝트 이름일 뿐 URL 경로가 아니다.** 따라서 API 는
  언제나 교차 출처이고, 백엔드의 CORS 옵트인이 배포의 전제 조건이다. 다만 **정적 배포에서는
  저장소 이름이 base path 가 된다** — 그래서 링크는 전부 상대경로다.
- **버전 정합 테스트는 리터럴을 박지 않는다.** 앱마다 자기 semver 를 드는지만 본다 —
  저장소 간 버전 비교는 하지 않는다(각자 독립 배포다).
- **판정을 화면이 다시 계산하지 않는다.** 드리프트·검증 판정·게인 계산은 백엔드가 하고 화면은
  그 답을 옮긴다. 두 번째 구현이 생기면 두 구현은 언젠가 서로 다른 답을 낸다.
- **다국어는 채우지 않는다**(이교수님 지시). `t()` 래퍼와 언어 셀렉터 구조는 유지하되 사전에
  번역을 채우지 않는다. 사전은 `src/i18n/dict.mjs` 에 데이터로만 있고, 규칙 파일과 다시
  붙는 것을 테스트가 막는다.

## Risks

- **발행본에 백업이 없다.** 프로파일은 git 밖 `localfiles/profiles/camera/` 에 있고 백업도
  복원 라우트도 **의도적으로** 없다(보드 #76 — 리그가 바뀐 곡선을 되살리는 기계가 #61 의
  재발이라서). 20분 스윕 결과를 잃으면 재측정뿐이다. **화면이 복원·백업을 약속하지 않게**
  지키는 것이 우리 몫이다.
- **혼합 콘텐츠.** https 정적 호스팅에서 http 백엔드는 브라우저가 차단한다. UI 가 부르기 전에
  판정해 알린다(`src/lib/api.mjs` `mixedContentBlocked`). 남은 리스크는 https 백엔드
  (또는 터널) 확보다.
- **CORS 는 이 저장소가 고칠 수 없다.** 백엔드가 배포 오리진을 허용해야 한다.
- **라우트 CSS 누적.** SPA 에서는 방문한 화면의 CSS 가 언로드되지 않는다. 전역 선택자와
  **app.css 가 소유하는 공유 id**(`#stage`·`#view`·`#viewbar`)를 라우트 CSS 가 덮으면, 그
  화면을 한 번 들른 뒤 다른 화면이 그 치수로 굳는다(실제로 CCTV 스테이지가 860×484 로
  얼어붙었다). 테스트가 둘 다 문다.
- **계약이 하루에 여러 번 바뀔 수 있다.** 2026-08-19 에 백엔드가 0.17.0→0.19.0 을 하루에
  올렸고, 같은 필드의 의미가 이틀 새 세 번 바뀐 적도 있다(`restartRequired`). 그래서 화면은
  응답을 읽고, **시점·상태를 예측해 문구에 박지 않는다** — 박으면 다음 변경에 조용한
  거짓말이 된다.
- **공개 이력은 되돌릴 수 없다.** 커밋 전에 유출 감사를 끝낸다. 사설 IP·실기 호스트명·계정명·
  토큰은 주석·placeholder·테스트 픽스처·문서 전부에서 뺀다.
