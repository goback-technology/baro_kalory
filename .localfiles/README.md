# `.localfiles/` — 이 기계에서만 사는 것들

**캐시·임시 산출물·받아 본 응답·실험 스크립트·덤프는 전부 여기에 쓴다.** git 은 이 안을
들여다보지 않는다(이 README 만 예외). 그래서 여기 쓴 것은 실수로도 저장소에 딸려
들어가지 않는다.

## 왜 자리를 정해 뒀나

2026-09-23, 구글 Apps Script 의 오류 페이지가 `body.txt` 라는 이름으로 **저장소 루트에**
떨어졌고 한 달을 그대로 있었다. 이 저장소와 아무 상관 없는 남의 응답 본문이었다.

이런 파일은 그 자체로는 무해하지만, `git add -A` **한 번이면 저장소로 들어간다.** 한 번
들어가면 이력에 남고, 남의 오류 페이지가 우리 저장소의 사실인 것처럼 굳는다. 그래서
「나중에 지우자」가 아니라 **애초에 떨어지는 자리를 옮긴다.**

## 규칙

- 저장소 루트에 임시 파일을 만들지 않는다. 여기로 경로를 준다:
  `curl -o .localfiles/resp.html …` · `node script.mjs > .localfiles/out.txt`
- 이 디렉터리는 **clone 직후에도 있다**(이 README 가 그 자리를 잡아 둔다) — 쓰는 쪽이
  `mkdir` 을 신경 쓸 필요가 없다.
- 여기 있는 것은 언제 지워도 좋은 것들이다. 지워서 아쉬운 것이라면 여기 있으면 안 된다.

## 여기가 아닌 것

- **빌드 산출물** — `dist/` 와 `public/app.css` 는 제 자리가 있고 이미 ignore 된다.
- **비밀값** — `.env`(예시는 `.env.example`). 이쪽으로 옮기지 않는다.
- **에이전트 세션의 스크래치패드** — 세션별 임시 디렉터리가 따로 있다. 저장소 안에 남길
  이유가 있는 것만 여기 둔다.

## 철자는 하나다

형제 저장소들이 `_localfiles`(baro_unreal)·`__localfiles`(mzok)를 쓰고, 문서에 나오는
`localfiles/profiles/camera/`(보드 #76)는 **백엔드 기계**의 경로다. 셋 다 이 저장소의
것이 아니다. 여기서는 **`.localfiles` 하나**만 쓴다 — 다른 철자로 만들면 ignore 되지 않아
`git status` 에 빨갛게 드러나고, 커밋되면 `test/repo-hygiene.test.mjs` 가 잡는다.
